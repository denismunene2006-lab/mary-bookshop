# Mary Bookshop Website

This is a modern, responsive demo website for a bookshop business built with HTML and CSS.
It showcases a polished hero section, product cards, service details, contact options, and a WhatsApp-based order flow.

## Live Demo

https://denismunene2006-lab.github.io/mary-bookshop/

## Built With

- HTML5
- CSS3

## Features

- Modern split hero layout with a featured image panel
- Product catalog with item-specific visuals
- Fixed navigation bar with mobile menu
- About, location, and contact sections
- WhatsApp order form for quick demo ordering
- Mobile-friendly responsive design

## Project Structure

- `index.html`
- `style.css`
- `assets/images/`

## Demo Notes

- The website is intended as a polished demo for a small bookshop.
- Product images and hero visuals are embedded directly in the page and can be swapped out for real shop photos later.

## Purpose

This project was created to practice:

- Styling with CSS
- Creating business-style layouts
- Building responsive pages
- Designing a more modern product showcase
