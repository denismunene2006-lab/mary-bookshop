# Mary Bookshop Website

This is a modern, responsive demo website for a bookshop business built with HTML, CSS, and Vanilla JavaScript.
It showcases a polished hero section, product cards, service details, contact options, and a WhatsApp-based order flow.

## Live Demo

https://denismunene2006-lab.github.io/mary-bookshop/

## Built With

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla ES6+)

## Features

- Modern split hero layout with a featured image panel
- Product catalog with item-specific visuals and "Order This" functionality
- **Dynamic View Switching**: Smoothly transitions between the shop and order form
- **Automated Order Pre-filling**: Pre-populates the order form based on the selected product
- Fixed navigation bar with mobile menu
- About, location, and contact sections
- **Scroll-Reveal Animations**: Enhances UX using the Intersection Observer API
- Mobile-friendly responsive design

## Project Structure

- `index.html`
- `style.css`
- `assets/images/`

## Demo Notes

- The website is intended as a polished demo for a small bookshop.
- Product images and hero visuals are embedded directly in the page and can be swapped out for real shop photos later.
